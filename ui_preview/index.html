第二批 · GitHub 上使用量最大的组件库（按 ★ 数）

方案 5 / 构建链

Ant Design 5 国内最流行 React

ant-design/ant-design · 约 93k ★
企业级 React 组件库，国内中后台事实标准
  • 优点：组件最全最稳（Statistic/Segmented/Table 开箱即用），暗色用算法主题一键切换、品牌色一个 token 全局生效；文档与社区资源最丰富
  • 代价：React + Vite 全量重写 + Node 构建链；体积较大；视觉偏「阿里系中后台」

Element Plus

element-plus/element-plus · 约 25k ★
国内 Vue 3 生态使用最广的组件库
  • 优点：Vue 3 生态最成熟的选择，暗色只需一个 html.dark class；中文文档一流；组件密度适中，与数据面板很搭
  • 代价：同样 Vue + Vite 全量重写 + Node 构建链；视觉辨识度一般（「后台管理」气质）

方案 7 / 构建链

Vuetify 3

vuetifyjs/vuetify · 约 40k ★
Material Design 组件库，国际使用量最大的 Vue UI
  • 优点：完整 Material Design 语言（app-bar/tabs/chips/cards 观感与其它方案差异最大）；主题系统精细；组件质感高
  • 代价：Vue + Vite 全量重写；Material 风格与军事/游戏题材的契合度见仁见智

方案 8 / 零构建

Bootstrap 5.3 用量之王

twbs/bootstrap · 约 172k ★
全球使用最广的 CSS 框架，5.3 起原生暗色
  • 优点：生态与成熟度无可争议；data-bs-theme 一行切换明暗；编译版 CSS 放进 web/vendor/ 即用，零构建、保持单二进制；与 Tabler 同底子但更轻
  • 代价：无聊天/统计等业务组件（本就靠自绘）；默认观感朴素，需要像示例这样调一层品牌色

第一批 · 风格化设计体系

方案 1 / 零构建

Tabler 推荐

tabler/tabler · 约 39k ★
成熟开源 dashboard 设计系统（Bootstrap 5 内核）
  • 优点：仪表盘组件最全（卡片/表格/徽章/统计条全内置），气质与本项目最契合；不引入 Node 构建链，保持单二进制分发
  • 代价：HTML 结构需按 Bootstrap 语义重写（JS 逻辑保留）；个性弱于 shadcn

方案 2 / 零构建

Tailwind + DaisyUI

saadeghi/daisyui · 约 35k ★
原子化 CSS + 组件类库
  • 优点：主题定制自由度最高（data-theme 切换全套配色）；chat 气泡/stats 组件观感现代；零构建
  • 代价：Play CDN 不适合生产；复杂排版要自己拼 utility class，长期一致性弱
